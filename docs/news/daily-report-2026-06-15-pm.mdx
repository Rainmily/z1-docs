## 大疆Pocket 4P 6/15发布：标准版3799元，1英寸大底+3倍长焦+10-bit D-Log 2

**2026-06-15 13:00**（今日）**大疆Pocket 4P手持云台相机正式发布**，**标准版套装3799元起售**。这是大疆在口袋云台相机赛道对影石Luna Ultra（3999元）的**正面对决**——前后差一天发布，是对着干。

### 大疆Pocket 4P核心配置

| 项目 | 配置 |
|------|------|
| **传感器** | **1英寸CMOS传感器**（首次延续至Pocket 4代） |
| **镜头** | **首次新增3倍光学长焦镜头**（Pocket 1-3代均为单焦段，被吐槽无法拍远景特写） |
| **色彩模式** | **10-bit D-Log专业色彩模式**（专业电影机级别规格） |
| **动态范围** | **17档动态范围** |
| **色彩曲线** | **D-Log 2专业色彩曲线** |
| **定位** | "**装进口袋里的电影机**"（大疆官方定义） |
| **价格** | **标准版套装3799元起** |
| **配色** | **珠光白**（上周北京"大疆光影十二载"技术分享会首次亮相实物） |

### 影石Luna Ultra（竞品，6/14发布）

| 项目 | 配置 |
|------|------|
| **传感器** | 1英寸双摄（徕卡双摄） |
| **分辨率** | **全球首款8K徕卡双摄云台相机** |
| **色彩** | 徕卡加持的影像调色 |
| **价格** | **首发价3999元**（限时起步价） |

### 3799元 vs 3999元：长焦对徕卡双摄

- **大疆Pocket 4P优势**：3倍光学长焦（拍演唱会/景区远景特写）+10-bit D-Log 2（电影级后期调色空间）+17档动态范围（高动态场景下高光和暗部细节保留）
- **影石Luna Ultra优势**：徕卡双摄（徕卡影像调色一贯讨喜）+8K分辨率（后期裁剪和二次构图有优势）

### 市场份额：大疆垄断式存在

**大疆Pocket系列占据92.9%市场份额**——这是Pocket系列之前的绝对地盘。影石Luna Ultra"对着开了一枪"——大疆同步回击Pocket 4P，且做了有诚意的升级（**补齐长焦+色彩专业级拉满**）。

### 大疆与影石的专利诉讼

大疆之前起诉影石侵犯多项专利，影石也反诉了。**这边官司还没完，那边新品发布档期直接撞在一起**，火药味浓。**大疆Pocket 4P 6/15发布+影石Luna Ultra 6/14发布=全球口袋云台相机赛道的"双雄对决"正式开始**。

**点评**：**Pocket 4P是Pocket系列历史上最大的一次产品力升级**——3倍光学长焦补齐了Pocket 1-3代"只能拍近不能拍远"的致命短板，10-bit D-Log 2让Vlog创作者从"业余拍"升级到"专业级调色"。**3799元对3999元的价格差（5%）+徕卡双摄对3倍长焦的差异化定位**，让消费者面临明确选择。**大疆92.9%份额的市场基础+影石在运动相机/全景相机的差异化积累**，口袋云台相机赛道进入"双雄并立"新阶段。

## 华为Mate 80系列累计销量670.56万部，国产高端第一

**2026-06-15** 快科技披露数码博主"RD观测"最新数据：截至2026年第23周（6/1-6/7），**华为Mate 80系列手机累计销量已达约670.56万部**。

### 销量走势

| 周次 | 日期 | 累计销量（万部） | 单周销量（万部） |
|------|------|------------------|------------------|
| W21 | 5/18-5/24 | 629.58 | — |
| W22 | 5/25-5/31 | 649.42 | 19.84 |
| **W23** | **6/1-6/7** | **670.56** | **21.14** |

### 关键分析

- **国产高端第一**：Mate 80系列作为**公认的国产高端旗舰标杆机型**，用户认可度一直很高
- **热度坚挺**：**上市已经度过了首发爆发期进入常规销售阶段**，**市场热度依旧十分坚挺**，**完全没有出现普通旗舰机型上市后期销量快速跳水的疲软态势**
- **国内整体手机市场周度销量第一**：份额**22.1%**（口径与22.68%略有差异），苹果同期**19.3%**——华为和苹果在高端机赛道的争夺战越演越烈
- **Mate 70系列对比**：Mate 70系列在整个产品生命周期内的累计销量突破了千万部，**按当前走量趋势推算，Mate 80系列达成千万销量的目标几乎没有太大难度**，而且**整个系列完成千万台销量所用的时间，还会比上一代Mate 70更短**

**点评**：**华为Mate 80系列年内破千万几无悬念**——按W22+W23平均单周销量20万计算，从W23（670.56万）到1000万还需约**164.7万**≈**8-9周**，对应**8月中旬达成**。Mate 80系列将成为继Mate 60系列、Mate 70系列后的**第三款"千万级国产高端街机"**，与iPhone 17系列形成"**国产+iOS双高端对决**"的核心格局。
