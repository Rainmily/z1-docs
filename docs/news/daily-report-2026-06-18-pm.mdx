**核心规格回顾**:
- 内屏:7.5 英寸 √2:1 大阔屏(2480×2200)
- 外屏:5.7 英寸
- 处理器:麒麟 9030
- 后置:5000 万像素 RYYB 主摄 + 4000 万超广角 + 1200 万潜望长焦(5 倍光变)
- 电池:5400mAh 硅碳负极
- 系统:鸿蒙 OS 7.0 Beta 1
- 起售价:7999 元

**点评**:Pura X Max 的成功印证了「阔折叠」将成为 2026 H2 旗舰赛道的核心共识。此前 OPPO Find N6、华为 Mate XT2(i 型双内折)、iPhone Ultra(书本式)均瞄准阔折叠方向,但 Pura X Max 是首个跑通「非传统比例 + 大众价位」组合的产品。华为凭借鸿蒙 OS 7 适配的横屏生态(平行视界 + 大屏应用重构)+ 麒麟芯片产能爬坡,在大阔折品类实现量价齐飞。
